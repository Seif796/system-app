# 📱 نظام توثيق المشاكل الذكي (SYSTEM)
### للهواتف الذكية: آيفون (iOS) وأندرويد (Android) مع ربط ومزامنة فورية

---

## 🌟 مميزات التطبيق
1. **واجهة AMOLED سوداء بالكامل:** شاشة سوداء أنيقة مع دائرة ضوئية زرقاء نيون مضيئة بداخلها علامة زائد (`+`).
2. **التقاط الصور والترقيم التلقائي:**
   - أول صورة يتم ترقيمها تلقائياً: **صورة رقم 1**.
   - ثاني صورة: **صورة رقم 2**.
   - ثالث صورة: **صورة رقم 3**، وهكذا تباعاً.
3. **سؤال حالة المشكلة:**
   - خيارين واضحين: **✅ تم الحل** أو **❌ لم تُحل بعد (قيد المتابعة)**.
   - حقل لكتابة وصف المشكلة أو الملاحظات.
4. **تحديد الموقع الجغرافي التلقائي (GPS Geolocation):**
   - يسحب التطبيق إحداثيات الـ GPS (خط الطول ودائرة العرض) تلقائياً وبدقة عالية.
   - يحدد اسم المنطقة/الشارع تلقائياً.
   - يوفر زراً مباشراً لفتح الموقع في خرائط Google (`Google Maps`).
5. **الربط والمزامنة بين الآيفون والأندرويد:**
   - نظام الغرف السحابية المشتركة (Room Code) - يتم إدخال نفس الرمز على الآيفون والأندرويد لمشاركة البلاغات والتعديلات.
   - دعم تصدير واستيراد النسخ الاحتياطية (ملف JSON).
6. **سجل البلاغات والفلترة:**
   - قائمة بجميع البلاغات مع إمكانية التكبير والتعديل والحذف وتغيير حالة الحل.

## 🚀 كيفية الرفع على GitHub للحصول على الرابط المباشر (GitHub Pages)

### الخطوة 1: إنشاء مستودع جديد على GitHub
1. اذهب إلى موقع [GitHub](https://github.com) وسجل دخولك.
2. اضغط على زر **New Repository** (مستودع جديد).
3. سمه مثلاً: `system-app`.
4. اجعله **Public** ثم اضغط **Create Repository**.

### الخطوة 2: رفع الملفات عبر التيرمينال (أو سحب وإفلات)
من نفس مجلد المشروع الحالي، نفذ الأوامر التالية:

```bash
git add .
git commit -m "Initial commit for System App"
git branch -M main
git remote add origin https://github.com/<YOUR_USERNAME>/system-app.git
git push -u origin main
```
*(استبدل `<YOUR_USERNAME>` باسم حسابك على GitHub)*

### الخطوة 3: تفعيل الرابط المباشر (GitHub Pages)
1. افتح صفحة المستودع على GitHub.
2. اضغط على **Settings** (الإعدادات).
3. من القائمة الجانبية اضغط على **Pages**.
4. تحت قسم **Build and deployment**، اختر:
   - Source: **Deploy from a branch**
   - Branch: اختر **main** ومجلد **/(root)** ثم اضغط **Save**.
5. بعد دقيقة واحدة، سيظهر لك الرابط باللون الأخضر مثل:
   👉 `https://<YOUR_USERNAME>.github.io/system-app/`

## 📲 كيفية التثبيت والتشغيل على الهواتف

### 🍏 على هاتف iPhone:
1. افتح الرابط المباشر في متصفح **Safari**.
2. اضغط على زر **المشاركة (Share)** أسفل الشاشة (أيقونة المربع الذي يخرج منه سهم).
3. انزل لأسفل واختر **إضافة إلى الشاشة الرئيسية (Add to Home Screen)**.
4. اضغط **إضافة (Add)**.
5. سيظهر التطبيق على شاشة الآيفون بأيقونته الزرقاء النيون، ويعمل كتطبيق كامل بشاشته السوداء وبدون شريط المتصفح!

### 🤖 على هاتف Android:
**الطريقة الأولى (التثبيت المباشر الفوري كـ PWA):**
1. افتح الرابط في متصفح **Google Chrome**.
2. ستظهر لك رسالة سريعة في الأسفل أو من القائمة **(⋮)** اختر **تثبيت التطبيق (Install App)**.
3. سيتم تثبيت التطبيق فوراً على هاتفك.

**الطريقة الثانية (توليد ملف APK مباشر):**
- يمكنك الذهاب إلى موقع [PWABuilder.com](https://www.pwabuilder.com) ووضع رابط الـ GitHub Pages الخاص بك، ثم الضغط على **Package for Android** لتحميل ملف الـ **.apk** الجاهز للتثبيت!
